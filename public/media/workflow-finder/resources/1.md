# Strapi 测评录入 Skill

将 Agent 或 AI Model 的测评结果录入到 Strapi 管理后台 [内部后台地址已移除]。

## 触发条件

当用户提到以下关键词时激活本 skill：
- "录入测评"、"上传测评"、"Strapi 录入"、"发布测评"
- "新增 agent"、"新增模型"、"测评结果上传"
- 或者用户直接给出测评截图 + 评分/评语，明确要求录入后台

## 用户需要提供的信息

用户只需提供以下信息即可（格式不限，AI 自动解析）：

**Agent** 需要提供以下信息：

```
- 类型：Agent
- 名称：测评对象名称
- 发布日期：YYYY.MM.DD
- 体验地址：URL
- 描述：一句话（~30字）
- 一句话推荐：~15字
- 产品体验：X分 + 评语（~18字）
- 任务完成：X分 + 评语（~18字）
- 生成质量：X分 + 评语（~18字）
- 总结分：X分
- 截图：4张（1.png 首页 / 2.png 测试页1 / 3.png 测试页2 / logo-1.png 标志）
```

**AI Model** 需要提供以下信息（无产品体验维度）：

```
- 类型：AI Model
- 名称：测评对象名称
- 发布日期：YYYY.MM.DD
- 体验地址：URL
- 描述：一句话（~30字）
- 一句话推荐：~15字
- 任务完成：X分 + 评语（~18字）
- 生成质量：X分 + 评语（~18字）
- 总结分：X分
- 截图：4张（1.png 首页 / 2.png 测试页1 / 3.png 测试页2 / logo-1.png 标志）
```

## 执行流程

### 第一步：确认信息
- 解析用户提供的信息，汇总展示
- 截图文件路径确认（通常在 /root/uploads/）

### 第二步：登录 Strapi
```
agent-browser open "[内部后台地址已移除]"
```
- 登录信息：请使用个人授权账号，公开版本不包含凭据。
- 登录信息：请使用个人授权账号，公开版本不包含凭据。

### 第三步：创建文件夹
- 进入 Media Library → agent（或 model）文件夹
- 查看当前最大数字编号
- 新建 `agent-{最大编号+1}` 或 `model-{最大编号+1}` 文件夹

### 第四步：上传图片
- 将 4 张截图上传到刚创建的文件夹
- 重命名为标准格式：`1.png`、`2.png`、`3.png`、`logo-1.png`
- **重命名时使用 keyboard type 而非 fill**，确保触发 Strapi React onChange

### 第五步：创建 Entry
- 进入 Content Manager → Agent（或 AI Model）
- 点击 "Create new entry"
- 填写所有字段：
  - **Agent**：填写全部字段（含产品体验分和产品体验评语）
  - **AI Model**：跳过 `product_exp_score` 和 `product_exp_comment`，其余字段正常填写

### 第六步：关联图片
- **icon 字段**：选择 logo-1.png
- **image 字段**：按 1→2→3 顺序依次选择（先选 1.png，再选 2.png，最后选 3.png）
  - 顺序决定展示位置：1 在最左，3 在最右

### 第七步：保存并发布
- 先 Save（确认 PUT 请求已发送）
- 再 Publish（确认 POST actions/publish 已发送）
- 回到列表页验证

## 字段映射与规范

| 字段名 | 含义 | 字数规范 | 类型 |
|---|---|---|---|
| name_display | 名称 | - | 文本 |
| desc | 描述 | ~30字 | 多行文本 |
| url | 体验地址 | - | URL |
| publish_date | 发布日期 | - | 日期 |
| usage_score | 使用评分 | 1-5 | 数字 |
| summary_score | 总结评分 | 1-5 | 数字 |
| summary_comment | 一句话推荐 | ~15字 | 多行文本 |

| product_exp_score | 产品体验分（**仅 Agent**） | 1-5 | 数字 |

## 图片命名规则

| 文件 | 用途 | image 位置 |
|---|---|---|
| 1.png/jpg | 产品首页截图 | 最左 |
| 2.png/jpg | 测试页面截图1 | 中间 |
| 3.png/jpg | 测试页面截图2 | 最右 |
| logo-1.png/jpg | 产品标志 | icon 字段 |

## 关键注意事项

### agent-browser fill 陷阱
- `agent-browser fill` 命令可能不触发 Strapi React 表单的 onChange
- 如果 Save 后刷新发现字段值未持久化，改用键盘输入：
  ```bash
  agent-browser click <textarea-ref>
  agent-browser press "Control+a"
  agent-browser keyboard type "新内容"
  agent-browser press "Tab"
  ```
- **验证方法**：hook fetch 后点击 Save，确认出现 `PUT /content-manager/collection-types/api::agent.agent/{documentId}` 请求

### 图片顺序
- image 字段添加时**严格按 1→2→3 顺序点击**，先选的排最左
- 如果顺序错了，需要全部删除后重新按正确顺序添加

### 文件夹编号
- 每次新增都在当前最大编号基础上 +1
- 如当前最大 agent-90 → 新建 agent-91
- 确认无重复编号

### 发布
- Strapi v5 发布调用 `POST /actions/publish`，直接点击 Publish 按钮即可
- 发布后回到列表页确认：名称、描述、状态（Published）、发布日期均正确

## 完成标志
- 列表页出现新 entry，状态为 Published
- 描述/评语均为简短一句话（符合字数规范）
- icon 显示 logo-1.png
- 截图顺序 1→2→3
- 文件夹命名连续递增
