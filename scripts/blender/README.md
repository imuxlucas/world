# 原创拆件资产 v001

本轮交付可逐件检查的结构初稿，不是最终美术验收版。全部在独立的 Blender background 进程中创建，没有修改用户打开的 Blender 文档；没有调用计费生成服务。

## 文件

- 可重跑生成器：`build_asset_parts.py`。
- 编辑母版：`asset-sources/{craft,link,island}/v001/source.blend`。
- 网页文件：`public/assets/{craft,link,island}/v001/model.glb`。
- 同目录附 `parts.json`、900 × 900 Blender 预览图、`geometry-report.json`。
- Link 另附 `route.json`，480 个近等弧长采样点、8 个吊舱及初始相位。
- `export-verification-v001.json` 记录实际 GLB 检查。

从项目根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/blender/build_asset_parts.py -- craft link island
```

重跑会覆盖对应的 v001 工作版本；正式锁定后应先改版本目录。`refresh_asset_palette.py` 和 `fix_gondola_pivots.py` 是本次构建中使用的可重跑迁移脚本；完整生成器已经包含同样修正。

## 层级与坐标

源文件使用米、Z 向上、-Y 为前方，原点为圆底座地面圆心。GLB 自动转换到 Y 向上。三件资产分别有 7、8、5 个语义顶层组；各组名称在 `parts.json.parts[].nodeNames` 中。

同一个语义部件中的固定几何按材质合批。Link 的 8 个吊舱是独立子组，轴心位于各自轨道悬挂点，带 `routeAnchor` 与 `completePostCount=8` 元数据。吊舱轴心迁移前后世界矩阵最大差值为 1.1920928955078125e-7，未改变可见布局。

`route.json` 的坐标仍为 Blender 的 Z-up；Three.js 中应映射 `[x,y,z] → [x,z,-y]`。轨道固定，吊舱沿路平移并保持竖直；本轮没有启用未经验证的轨道动画。

## 待逐件确认与精修

- Craft：当前尺寸与结构是基于选定图的原创解释；代码屏幕字形后续可换纹理，继续调整玻璃、环梁厚度和局部高光。
- Link：轨道是两颗同高心形的并集外边界，唯一闭合路线；8 个吊舱每件都有 8 根贯通顶棚与地板的柱。丘比特雕塑尚未制作，未用粗糙人形冒充完成。
- Island：放射铺装和花瓣曲线为可编辑样稿，完整穆夏纹样尚待精修；建议确认后烘成独立清晰贴图，降低绘制次数。

最终美术比例、动效与总场景的 120° 等距摆放在单体确认后继续。本轮没有替用户做最终确认。
