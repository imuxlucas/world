# Link v011 · 共面轮体与镜像斜撑

在 v009 上直接重建，保留旧版本、分片顶棚与原始丘比特雕像。

- 横梁、辐条保持在轨道平面内，无向后伸出的连接段；轮毂仅由 2.75 上移至 2.85。删除贯穿丘比特的单根中间横梁。
- 右侧内斜辐条在同一平面内接到下缘轨道，避开下移后的丘比特翅膀。
- 前 A 架与后撑以轨道平面镜像对齐，上端仍接入轮毂下方。顶端高度 2.47、前后坐标 0，底脚前后展开至 ±1.42，侧面斜向落地。外侧底脚设承托垫，连接圆盘台阶。
- 丘比特深度中心对齐轨道平面，下移 0.419 到双心下方交会处，保留托腮与双肘姿态。
- 吊舱连接杆由 0.50 缩至 0.28，完整舱体靠近轨道 0.22，保留顶棚、立柱和栏杆的比例。
- 去掉 64 片深蓝实心侧板及 8 个中央圆座。保留通透金属栏杆，内侧增加浅蓝环形沙发、分段软垫与白色滚边。
- 8 个车厢按闭合轨道实际弧长等间隔排布，静态与动画起点一致，顺时针 48 秒一圈且保持直立。

源文件：`asset-sources/link/v011/source.blend`；网页模型：`public/assets/link/v011/model.glb`。重建脚本：`scripts/blender/refine_link_v011.py`。

`scripts/blender/check_link_v011_motion.py` 加载源文件的实际求值三角网格，在 640 个轨道点及每段中点检查车厢与支架、辐条、设备、丘比特和底座的相交，共 1,280 个位置，最大相邻步长约 0.00918。轨道滑架的设计连接界面排除。报告保存于同版本目录 `motion-check.json`，结构尺寸保存于 `structure-check.json`。

运行时另检查一圈 961 组姿态的等弧长间距、顺时针方向、路径误差、直立和闭合。正面、侧面、斜视及近景截图保存在 `artifacts/link-v011-*.png`。

`scripts/blender/check_link_v011_alignment.py` 验证辐条和丘比特的深度中心、后伸构件移除，并以实际三角网格检查雕像与辐条、轮毂相交，报告为 `alignment-check.json`。
