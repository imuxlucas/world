# Link v010 · 通透车厢、均匀间距与运行避让

此版本为未上线的过程稿。支架和后置辐条方案已按用户反馈撤销，当前交付见 `LINK_V011.md`。

在 v009 基础上修改，保留旧模型和原始丘比特资产。

- 移除 64 片深蓝实心侧板、8 个中央圆座。保留金属栏杆和贯通立柱，内侧增加浅蓝环形沙发，分为八块软垫，配低靠背和细白滚边。
- 8 个车厢沿双心闭合轨道按弧长八等分，间隔约 1.4682 模型米；每圈仍为 48 秒，顺时针运动且始终直立。静态 GLB 与网页动画采用相同起始相位。
- 前后支架脚点由 ±0.64 展开至 ±1.00；支架上端分开，给顶棚、吊杆和车厢留出连续运行空间。
- 轮毂中心由 2.75 上移至 3.03，设备面板与轮毂同步调整；轴藏在轮毂后面。
- 删除贯穿丘比特的横梁，保留原有托腮造型，下移到双心下方交会处。辐条移至丘比特后层，避免遮挡和穿过雕像。

源文件：`asset-sources/link/v010/source.blend`；网页模型：`public/assets/link/v010/model.glb`。重建脚本：`scripts/blender/refine_link_v010.py`。原始照片和用户参考图没有被修改。

运行时均匀间距在 `src/assetMotion.ts` 中实现。通过闭合轨道弧长计算各车厢相位，不按轨道样本索引或图上直线距离排布。

验证报告 `asset-sources/link/v010/clearance-check.json` 检查实际几何部件包围盒在全部 640 段轨道上的连续扫掠，覆盖车厢与支架、辐条、设备、丘比特和底座；轨道与车厢滑架的设计连接界面单列。雕像与结构件存在包围盒重叠时，再用实际三角网格检查，避免把斜杆的大包围盒误判成穿模。此检查针对网页里的直立平移动画。

视觉检查包含车厢、丘比特近景、正面、侧面、斜视，以及多个动画时刻。截图保存在 `artifacts/link-v010-*.png`。
