# 完整微缩乐园 · v001

入口：`/#park`，无 hash 时也默认进入组合场景。资产检查页保留在 `/#carousel` 等原路由，顶部可返回完整乐园。

## 布局

Three.js 使用 Y 向上、+Z 面向观众。共用圆盘沿用 Island v009，铺装高 0.566。摩天轮 Link v009 位于后方 `(0,-2.15)`、缩放 1.05；Craft v003 位于左前 `(-2.5,1.45)`、缩放 1.18；Carousel v005 位于右前 `(2.55,1.4)`、缩放 0.60。建筑统一按实际几何最低点落地，整体比例和参考图一致的三角布局优先，不修改源模型。

页面与 WebGL 背景均为纯白。动画运行时以 20 Hz 更新阴影，暂停时停止；共用场景中将昂贵的玻璃折射改为轻量透明显示，单模型页和源材质不变。可旋转、缩放、恢复参考视角。

## 小黑柴犬

复用 Dog v002 的 `Walk_InPlace` 蒙皮步行动画，以 0.27 倍比例在空地间散步。通过圆盘边界和三个底座的膨胀圆形碰撞区规划路径，逐段进行采样验证，再执行前进、转向、短暂停留。碰撞半径 0.30，额外留边 0.065；运动不依赖页面滚动。支持暂停/继续，页面隐藏时暂停，自适应减少动态效果偏好。

`src/parkNavigation.ts` 管理布局和寻路；`src/ParkScene.tsx` 管理组合渲染、动画和销毁。`scripts/check-park-navigation.mjs` 验证所有可选点对路径和底座布局；`scripts/check-park.cjs` 验证加载、移动、暂停继续和移动端布局。

## 可编辑组合源文件

`asset-sources/park/v001/source.blend` 由 `scripts/blender/assemble_park_v001.py` 装配，原件保持不变，`assembly.json` 记录来源和 SHA-256。源文件保留狗的绑定及导入动画；自主寻路是在网页运行时实现，不宣称 Blender 文件已经烘焙同样的闲逛轨迹。


三主体动画已接入：双心轨道车厢顺时针运行、旋转木马联动、Craft 代码流光。实现与验证见 [三主体运行时动画](ASSET_ANIMATIONS.md)。
